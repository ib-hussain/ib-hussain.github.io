# Public content safeguards

- The portfolio never asserts completed status for work marked in development.
- MobileInfoAnalytics acknowledges collaboration with Malaika Khan; frag-aware scheduler acknowledges a collaborator-owned repository.
- PTCL and SmartForum details use verified or previously supplied descriptions, and no SmartForum dates are invented.
- A project detail window displays metadata from the page; clicking a card opens it. All three macOS traffic-light controls in the open window close the dialog.
- Movies uses an empty JSON dataset until the owner provides a Letterboxd account or export.
- Music does not distribute copyrighted recordings; local browser-only file playback is supported.
- Photo artwork is explicitly labelled illustrative.
