🧠 How the Flutter Web Mechanism Was Ported to HTML/JS

In the original Flutter Web app, the developer wrapped the root widget tree with a custom Stack containing a pointer Listener:

  • Jerry (Pointer): Directly tied to mouse coordinates, positioned at (x - 25, y - 25). Click sets size to 32×32.
  • Tom (Chaser): Driven by a continuous animation loop (requestAnimationFrame in JS / Ticker in Flutter) that interpolates towards Jerry's vector coordinates.
  • Sprite Direction: Inverts scaleX(-1) whenever velocity flips left/right so characters face the motion direction.
  • Collision: When Euclidean distance $d < \text{threshold}$, Tom & Jerry are hidden, and fight.gif (265×120 px) is displayed at (x - 132.5, y - 30).
